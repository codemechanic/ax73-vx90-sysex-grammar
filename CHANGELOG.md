# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [1.1.0] - 2026-10-29

### Fixed
- Updated Python scripts to Python 3 syntax for compatibility with Synalyze It! Pro 1.26+
- Fixed integer division (`/` to `//`) in all data type scripts and grammar
- Updated shebangs from `python` to `python3`

## [1.0.0] - Initial Release

### Added
- Akai AX73 and VX90 MIDI Sysex grammar for Synalyze It! and Hexinator
- Custom and general data type Python scripts
- Factory sysex files and documentation
